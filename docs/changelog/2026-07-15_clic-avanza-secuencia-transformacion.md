# Clic para avanzar la secuencia de transformación

Fecha: 2026-07-15  
Tarea: backlog #165

## Qué cambia

- El clic sobre el marco de las fases avanza a la imagen siguiente.
- Al alcanzar la quinta fase, el siguiente clic vuelve a la primera.
- El marco deja de abrir la imagen activa en el lightbox.
- El avance automático y los selectores numerados mantienen su comportamiento.

## Por qué

El bloque representa etapas consecutivas de una misma obra. Usar toda la imagen como control de avance hace explícita esa secuencia y evita interrumpirla con una vista ampliada.

## Despliegue

El cambio se prepara exclusivamente para `gurru-test.unlimited-systems.net`; no se modifica ni se despliega `gurruchagaweb.com`.
